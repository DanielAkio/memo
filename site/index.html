Jot it down in seconds

Double-click the top bar to name it. Type [] for a checklist and tick items as you go, - for a list, 1. for a numbered one, select a line to highlight it. Rather click? The Aa toolbar does the same with the mouse.

Put a command between backticks (`npm run dev`) and it shows as code; ``` starts a whole code block with colours for its language. Paste a screenshot straight in, too.

Pick a colour so you know what's what at a glance, or any colour you like with the eyedropper.

Keep related memories together

A group is a slim bar that holds memories. One click tucks them all away, another brings them back right where they were.

Drop a memory on a bar to add it to the group. Each group gets a colour of its own, which tints its memories so you can tell them apart.

Everything in one place

The Memo Manager lists every memory, open or closed. Search, sort, move one to a group or reopen it with a click.

Trashed something by mistake? Restore it: the trash keeps memories for 30 days.

Every bar keeps just the buttons you use most. The … button, or a right click on any bar, opens all of Memo's commands, from a new group to Settings, wherever you are.

Let your AI assistant take notes

Turn on AI control in Settings and click Connect next to your assistant: Claude, Codex, GitHub Copilot in VS Code, Cursor, Windsurf, Gemini CLI and Cline are set up for you, and any other app that speaks MCP takes one copy and paste.

Then just ask: "put my shopping list in a yellow memory and pin it". You watch the memories change on screen. It's off until you turn it on, only apps on your computer can connect, and deleting for good stays with you.

Always up to date

You only download Memo once. When a new version is out, Memo tells you in the tray menu and in Settings, and one click updates it and opens it again, memories and all.

Settings also shows which version you have, and you can check for a new one any time.

On all your computers, if you want

Sync is optional. Sign in with Google and your memories stay the same on every computer. They are stored in Memo's private folder in your own Google Drive: there is no Memo server, and Memo can't see any other file in your Drive.

Opening Memo on a Mac for the first time

The first time you open Memo, macOS blocks it and says it couldn't verify that Memo is free of malware. Nothing is wrong with the app: Apple only skips this warning for apps whose developer pays for the Apple Developer Program (US$ 99 a year), and Memo is a free project that doesn't. Its code is open on GitHub for anyone to check.

You only need to allow it once:

  1. Open the downloaded file and drag Memo to Applications.
  2. Open Memo. When the warning appears, click Done (or OK), not Move to Trash.
  3. Open System Settings → Privacy & Security and scroll down to Security.
  4. Next to the message about Memo, click Open Anyway and confirm with your password or Touch ID.

From then on Memo opens normally. A new version may ask once more. If macOS says the app "is damaged", run xattr -cr /Applications/Memo.app in Terminal and open it again.

Your browser or Windows warns about the download?

Browsers and Windows trust an installer more when it carries a digital signature (a code-signing certificate, which costs hundreds of dollars a year) and has already been downloaded by many people. Memo is a new, free project and its installer isn't signed yet, so you may see that the file "isn't commonly downloaded" or "could harm your device". Nothing is wrong with it: the installer is built straight from the code on GitHub, which is open for anyone to check.

To install it:

  1. If the browser holds the download, open its downloads list (Ctrl+J) and choose Keep. In Edge: … → Keep → Show more → Keep anyway.
  2. Open the downloaded file. If you see "Windows protected your PC", click More info, then Run anyway.
  3. Follow the installer. You only need to do this once.
