Jot it down in seconds

Anote em segundos

Double-click the top bar to name it. Type [] for a checklist and tick items as you go, - for a list, 1. for a numbered one, select a line to highlight it. Rather click? The Aa toolbar does the same with the mouse.

Dê um duplo clique na barra de cima para dar um nome. Digite [] para uma lista de tarefas e marque os itens conforme avança, - para uma lista, 1. para uma numerada, selecione uma linha para destacá-la. Prefere clicar? A barra Aa faz o mesmo com o mouse.

Put a command between backticks (`npm run dev`) and it shows as code; ``` starts a whole code block with colours for its language. Paste a screenshot straight in, too.

Coloque um comando entre crases (`npm run dev`) e ele aparece como código; ``` abre um bloco de código inteiro, com as cores da linguagem. Dá para colar um print direto, também.

Pick a colour so you know what's what at a glance, or any colour you like with the eyedropper.

Escolha uma cor para saber o que é o quê num relance, ou qualquer cor que quiser com o conta-gotas.

Keep related memories together

Memórias do mesmo assunto, juntas

A group is a slim bar that holds memories. One click tucks them all away, another brings them back right where they were.

Um grupo é uma barrinha que reúne memórias. Um clique guarda todas, outro as traz de volta exatamente onde estavam.

Drop a memory on a bar to add it to the group. Each group gets a colour of its own, which tints its memories so you can tell them apart.

Solte uma memória sobre a barra para colocá-la no grupo. Cada grupo ganha uma cor própria, que tinge as suas memórias para você distingui-las.

Everything in one place

Tudo num só lugar

The Memo Manager lists every memory, open or closed. Search, sort, move one to a group or reopen it with a click.

O Gerenciador do Memo lista todas as memórias, abertas ou fechadas. Busque, ordene, mova para um grupo ou reabra com um clique.

Trashed something by mistake? Restore it: the trash keeps memories for 30 days.

Mandou algo para a lixeira sem querer? É só restaurar: a lixeira guarda as memórias por 30 dias.

Every bar keeps just the buttons you use most. The … button, or a right click on any bar, opens all of Memo's commands, from a new group to Settings, wherever you are.

Cada barra mostra só os botões que você mais usa. O botão …, ou um clique com o botão direito em qualquer barra, abre todos os comandos do Memo, de um grupo novo às Configurações, de onde você estiver.

Let your AI assistant take notes

Deixe a sua IA anotar por você

Turn on AI control in Settings and click Connect next to your assistant: Claude, Codex, GitHub Copilot in VS Code, Cursor, Windsurf, Gemini CLI and Cline are set up for you, and any other app that speaks MCP takes one copy and paste.

Ligue o Controle por IA nas Configurações e clique em Conectar ao lado do seu assistente: Claude, Codex, GitHub Copilot no VS Code, Cursor, Windsurf, Gemini CLI e Cline são configurados para você, e qualquer outro app que fale MCP só precisa de um copiar e colar.

Then just ask: "put my shopping list in a yellow memory and pin it". You watch the memories change on screen. It's off until you turn it on, only apps on your computer can connect, and deleting for good stays with you.

Depois é só pedir: "coloca minha lista de compras numa memória amarela e fixa". Você vê as memórias mudarem na tela. Fica desligado até você ligar, só apps do seu computador conseguem se conectar, e apagar de vez continua com você.

Always up to date

Sempre atualizado

You only download Memo once. When a new version is out, Memo tells you in the tray menu and in Settings, and one click updates it and opens it again, memories and all.

Você só baixa o Memo uma vez. Quando sai uma versão nova, o Memo avisa no menu da bandeja e nas Configurações, e um clique atualiza e abre de novo, com todas as memórias.

Settings also shows which version you have, and you can check for a new one any time.

As Configurações também mostram qual versão você tem, e dá para procurar uma nova quando quiser.

On all your computers, if you want

Em todos os seus computadores, se quiser

Sync is optional. Sign in with Google and your memories stay the same on every computer. They are stored in Memo's private folder in your own Google Drive: there is no Memo server, and Memo can't see any other file in your Drive.

A sincronização é opcional. Entre com o Google e suas memórias ficam iguais em todos os computadores. Elas ficam na pasta privada do Memo no seu próprio Google Drive: não existe servidor do Memo, e o Memo não vê nenhum outro arquivo do seu Drive.

Opening Memo on a Mac for the first time

Abrindo o Memo no Mac pela primeira vez

The first time you open Memo, macOS blocks it and says it couldn't verify that Memo is free of malware. Nothing is wrong with the app: Apple only skips this warning for apps whose developer pays for the Apple Developer Program (US$ 99 a year), and Memo is a free project that doesn't. Its code is open on GitHub for anyone to check.

Na primeira vez que você abre o Memo, o macOS bloqueia o app e diz que não pôde verificar se ele está livre de malware. Não há nada de errado com o app: a Apple só dispensa esse aviso para apps cujo desenvolvedor paga o Apple Developer Program (US$ 99 por ano), e o Memo é um projeto gratuito que não paga. O código é aberto no GitHub para qualquer pessoa conferir.

You only need to allow it once:

Você só precisa liberar uma vez:

  1. Open the downloaded file and drag Memo to Applications.
  2. Abra o arquivo baixado e arraste o Memo para Aplicativos.
  3. Open Memo. When the warning appears, click Done (or OK), not Move to Trash.
  4. Abra o Memo. Quando o aviso aparecer, clique em Concluído (ou OK), e não em Mover para o Lixo.
  5. Open System Settings → Privacy & Security and scroll down to Security.
  6. Abra Ajustes do Sistema → Privacidade e Segurança e role até Segurança.
  7. Next to the message about Memo, click Open Anyway and confirm with your password or Touch ID.
  8. Ao lado da mensagem sobre o Memo, clique em Abrir Mesmo Assim e confirme com sua senha ou Touch ID.

From then on Memo opens normally. A new version may ask once more. If macOS says the app "is damaged", run xattr -cr /Applications/Memo.app in Terminal and open it again.

Depois disso o Memo abre normalmente. Uma versão nova pode pedir isso mais uma vez. Se o macOS disser que o app "está danificado", rode xattr -cr /Applications/Memo.app no Terminal e abra de novo.

Your browser or Windows warns about the download?

O navegador ou o Windows avisam sobre o download?

Browsers and Windows trust an installer more when it carries a digital signature (a code-signing certificate, which costs hundreds of dollars a year) and has already been downloaded by many people. Memo is a new, free project and its installer isn't signed yet, so you may see that the file "isn't commonly downloaded" or "could harm your device". Nothing is wrong with it: the installer is built straight from the code on GitHub, which is open for anyone to check.

Navegadores e o Windows confiam mais em um instalador quando ele tem uma assinatura digital (um certificado de assinatura de código, que custa centenas de dólares por ano) e já foi baixado por muita gente. O Memo é um projeto novo e gratuito e o instalador ainda não é assinado, então pode aparecer que o arquivo "não é baixado com frequência" ou "pode danificar o dispositivo". Não há nada de errado com ele: o instalador é gerado direto do código no GitHub, que é aberto para qualquer pessoa conferir.

To install it:

Para instalar:

  1. If the browser holds the download, open its downloads list (Ctrl+J) and choose Keep. In Edge: … → Keep → Show more → Keep anyway.
  2. Se o navegador segurar o download, abra a lista de downloads (Ctrl+J) e escolha Manter. No Edge: … → Manter → Mostrar mais → Manter assim mesmo.
  3. Open the downloaded file. If you see "Windows protected your PC", click More info, then Run anyway.
  4. Abra o arquivo baixado. Se aparecer "O Windows protegeu o computador", clique em Mais informações e depois em Executar assim mesmo.
  5. Follow the installer. You only need to do this once.
  6. Siga o instalador. Isso só precisa ser feito uma vez.
